### What I do

- 🏗️ **Backend systems end-to-end** — design, build, and ship production microservices using **Java / Spring Boot** with **Hexagonal Architecture** and clean domain layering.
- 🔄 **Event-driven & orchestrated workflows** — **Apache Kafka** for asynchronous decoupling, **Camunda (BPMN)** for long-running business processes, **Redis** for distributed locking and consistency.
- 🌐 **REST APIs & integrations** — secure services with **Keycloak / OAuth2**, inter-service comms with **Feign + Eureka**, persistence with **JPA / Hibernate** on **PostgreSQL** and **Oracle**.
- 🐍 **Polyglot delivery** — also build with **Go** and **Python / FastAPI** depending on what the problem needs.
- 🚀 **Containerized delivery** — **Docker**, **OpenShift**, and **Argo CD** in real production environments.
- 🤝 **Agile & ownership** — comfortable owning features end-to-end, collaborating across remote teams, and shipping predictably.
